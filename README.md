## 🚀 Unprecedented Features

### 🪐 1. Gyroscopic Kinetic Gravity Engine
Forget scrolling. VoteSaathi traps the user in a 3D cinematic hyperspace.
- **Hardware-Accelerated Tilt**: On desktop, the entire Matrix sways to your mouse movements. On mobile, it hooks directly into the device's hardware `DeviceOrientation` gyroscope, mapping your physical world to the digital realm.
- **Cinematic Tunnelling**: Scene transitions punch through the Z-axis with chromatic aberration and deep motion blur.

### 🧠 2. Sentient AI Matrix (Two-Way Voice)
Powered by **Gemini 2.5-Flash**, VoteSaathi isn't just an app; it's an entity.
- **Interruptible Voice Engine**: Tap the holographic microphone to instantly pause the application's timeline. Ask any election-related question using natural speech.
- **Holographic Thought Processor**: A dynamic visualizer reacts in real-time as the AI computes and responds with a seamless synthesized voice.

### 🗳️ 3. CSS-3D AR Hologram (EVM In Your Room)
Zero WebGL. Pure DOM manipulation.
- **Augmented Reality View**: Requests camera access to project a live feed as the background.
- **Preserve-3D EVM**: Constructs a massive Electronic Voting Machine entirely out of glassmorphic CSS layers suspended in 3D space (`transform-style: preserve-3d`).
- **Interactive VVPAT**: Press the blue button and watch a physics-based VVPAT slip physically eject from the 3D machine to verify your vote.

### 👁️ 4. Adaptive Neuroscience UI
Accessibility that actually changes how the brain processes information.
- **PictoPolitics**: Transforms the UI for visual learners. Replaces harsh shapes with rounded, high-border elements, warm colors, and highly legible typography.
- **NeuroSaathi**: Specifically engineered for neurodivergent users (Autism/ADHD). Strips all animations, transitions, and sensory overloads, rendering a perfectly calm, low-contrast pastel environment.

## 🛠️ Technology Stack

- **Core**: Next.js 16 (App Router, Turbopack), React 19
- **Styling**: Tailwind CSS v4, Vanilla CSS variables
- **Motion**: Framer Motion (Spring Physics)
- **Intelligence**: Google Gemini API (`@google/genai`)
- **Native APIs**: Web Speech API (Synthesis & Recognition), WebRTC (Camera), DeviceOrientation API

## ⚙️ Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/your-username/votesaathi.git
cd votesaathi

# 2. Install dependencies
npm install

# 3. Setup Gemini API Key
echo 'NEXT_PUBLIC_GEMINI_API_KEY="your_api_key_here"' > .env.local

# 4. Ignite the Matrix
npm run dev
```

Visit `http://localhost:3000`. 
*Note: For the full AR and Gyroscopic experience, test on a mobile device over a secure network (HTTPS or local IP).*
